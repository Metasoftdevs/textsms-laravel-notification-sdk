## v0.x → v1.0

The package's first stable release. There is no v0.x lineage published
on Packagist. If you have been tracking `dev-main` during development,
the v1.0 tag is the same surface — no migration is required.

## Reporting upgrade issues

Open an issue on the GitHub repository tagged `upgrade-guide` with:

- The version you upgraded **from**.
- The version you upgraded **to**.
- A minimal reproduction or a stack trace.
